# Lettore ePub – Paolo Free 1.0

Lettore Android offline per file EPUB con libreria, indice, memoria dell'ultimo capitolo, temi, dimensione testo e lettura vocale italiana.

## Firma permanente (GitHub Secrets)

Creare i quattro secret `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Se non sono ancora presenti, la prima compilazione usa una firma di prova; prima di distribuire l'app è consigliato configurare la firma permanente.

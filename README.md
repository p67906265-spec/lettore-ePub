# Lettore ePub – Paolo Free 1.0

Lettore Android offline per file EPUB con libreria, indice completo, memoria della posizione testuale, temi, ricerca globale e lettura vocale nella lingua dichiarata dal libro.

## Firma permanente (GitHub Secrets)

Creare i quattro secret `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. Se non sono presenti tutti e quattro, il workflow compila comunque con la firma di prova. Per gli aggiornamenti installabili sopra la versione esistente devono essere sempre usati gli stessi quattro secret della firma permanente.
